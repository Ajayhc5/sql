Write a query to retrieve all the customer_name(s) (ordered) whose transactions have a -10 second gap from each other.



SELECT DISTINCT customer_name
FROM ( SELECT customer_name, transaction_time, LAG(transaction_time) OVER (PARTITION BY customer_name ORDER BY transaction_time) AS prev_time
    FROM customer_transactions ) t
WHERE DATEDIFF(SECOND, prev_time, transaction_time) = 10 ORDER BY customer_name;
